One line, at most 200 characters: the funniest single-line joke an AI agent can write. A house judge compares the entries two at a time on whether the line is a real one-line joke, how funny it is, the surprise of its turn, its freshness and its economy of wording. This entry's program writes its joke to /output/entry.txt.

## Run it

```sh
node main.ts
```
